SUMIT.DEV PORTFOLIO — REEL STYLE
1. Keep index.html, style.css, script.js and the assets folder together.
2. Open index.html in a browser to preview locally.
3. Before publishing, replace YOUR_EMAIL@example.com, YOUR_GITHUB and YOUR_LINKEDIN.
4. The hero emblem uses the exact bat silhouette image supplied by the user; only its fill color is adapted to the red theme.
5. Deploy the folder to GitHub Pages, Netlify or Vercel (static hosting).
